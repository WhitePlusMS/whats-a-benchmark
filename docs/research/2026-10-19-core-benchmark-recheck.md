## 目录逐项对照

读取 `content/benchmarks` 下 156 份 JSON 记录，对完整记录中的名称、别名和来源等字段检查候选名称，并对母项、变体和别名作语义复核。没有确认直接身份匹配，故各条 `catalogIds` 为空；此处只表示当前目录未有这些完整身份，不表示没有相邻基准或构件。

检索中的词面假命中已排除：`LoCoMo` 只以子串出现在 MRCR v2 来源文字的 “welcome” 中；`PSI` 出现在 frontiermath、mmlu、tonebench 的一般指标文字中。它们不是目录名称、别名或身份链接。目录中的同系列/相关项（例如 MRCR v2、SWE-Bench 系列、Tax Agent Bench、Terminal-Bench、Vibe Code Bench）不能直接替代候选身份。

## 新增的一手定义证据

ChartQA Pro 并非只有发布图标签：作者论文发表于 ACL 2025 Findings（不是 CVPR 2025），并链接作者代码与数据集；论文摘要称 1,341 张图、1,948 个问题。其与 ChartQA 原版有关联，但属于独立 benchmark。

Riemann-bench 的发布方是 Surge AI。发布说明称其为 25 道专家整理的研究级数学题，并明确题目私有；说明还记载了评测时限流程的更新。因此，它有正式定义，但题库不能由外部复现。

CWE-bench v1 的发布方是 Collinear AI。官方页和 v1 公告定义为 120 个审计修补任务、覆盖 73 种 CWE，且 held-out 题目私有。Artificial Analysis 的 CWE-Bench-AA 是独立运行/报告标识，不能据名称把其分数与发布方 leaderboard 自动当作同一 harness。

## 分类与计数

当前 JSON 分类计数：指数、维度、同义或相关已有项 2 项、正式定义/研究证据 27 项、正式具名私有评测 5 项、仅有发布标签，定义未核实 1 项、定义部分核实 1 项。这些是证据状态数，不等于应收录或新增条目数。

- **正式定义/研究证据**：有评测方、论文或作者项目页支持身份与任务定义；题目集可公开，也可能由发布方保密。
- **正式具名私有评测**：厂商/机构明确披露评测定义或用途，但未公开完整任务集。
- **仅有发布标签，定义未核实**：能确认发布资料中出现该名，基准 owner、任务或与同名项目关系仍需核实。
- **定义部分核实**：有官方结果或场景页，但完整方法、owner 或可复现条件未证实。
- **指数、维度、同义或相关已有项**：该名称是复合指标、名称变体、子项或附近目录条目；不能重复作为一套独立题集。

逐项 `owner`、`definitionFound`、`catalogIds`、版本/同义关系和未确认事项均保存在 JSON 中。
