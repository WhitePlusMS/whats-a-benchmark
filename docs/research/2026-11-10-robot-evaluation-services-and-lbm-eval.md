# 机器人评测服务、成本与 LBM Eval 候选

调查日期：2026-11-10。只读公开资料；未注册、订购、运行仿真、操作机器人或访谈客户。报价、功能与运行状态会变化；所有厂商描述均未经本站验收。

## 与本站已有评测的关系

本站 [LIBERO](../../content/benchmarks/libero.json)、[RoboTwin 2.0](../../content/benchmarks/robotwin-2.json) 和 [RoboDojo](../../content/benchmarks/robodojo.json) 包含机器人操作评测，但各自的任务与环境不同。[TRI 的 LBM Eval](https://github.com/ToyotaResearchInstitute/lbm_eval)是另一套基于 Drake 的仿真 benchmark，仓库描述 49 项任务，提供训练数据格式、策略服务接口和运行说明；原作者说明公开软件比原论文实验用版本更新，不保证重现论文结果。以 `lbm_eval`、`LBM Eval` 等有限写法搜索本地 research 与正式 JSON，未见独立同名条目；不能据此断定所有别名和外部关联均不存在。它是待进一步核验的候选，未加入正式目录。

## 复现研究：成本和成功分母分别是什么

[第三方研究论文 v1](https://arxiv.org/html/2611.07441v1)使用 LBM Eval 的 `pick_and_place_box` 单项仿真任务，报告一次 200 回合评测使用 8 个并行分片、约 4.36 L4 GPU 小时、墙钟 37.7 分钟，按每 GPU 小时 0.80 美元计约 **3.49 美元**；训练加一次评测约 3.85 美元。它是论文报告的特定云算力条件及单任务成本，不是真机测试报价，也不包括可普遍转移到其他项目的人工、数据准备或所有维护费用。

作者发现 200 个场景中 5 个初始状态在策略有效动作前已满足目标并判成功；论文报告其按规则排除后以 **195** 个场景为分母，并检查成功录像。例如表中某策略保留全部场景为 7.5%，按筛选规则则为 5.1%；不能把它们当同一种分母的结果，也不应由该单任务推断 LBM Eval 49 个任务都有同样问题。初始筛选和视频核查均为作者报告，本站未复现或核验逐帧影像。

[作者代码仓库](https://github.com/rohungry/evaluation_harness_wrapper)提供分片、训练和逐回合结果，并声明部分依赖未固定、无完整 lockfile；原始示范数据来自 TRI 而非该仓库再分发。论文作者称处理了渲染环境、脚本路径和检查点格式等问题，这是亲历复现障碍的第一手记录；他们同时是方案作者，不等于独立客户，更不代表已验证资料站需求。

## 已有产品与报价：服务类别不能混同

- [HUD × Dreamscale 技术文章](https://www.hud.ai/research/evaluating-robot-models-in-the-cloud)描述利用云端策略推理、仿真、轨迹记录和分析，关联本站 LIBERO、RoboDojo 及 RoboLab 等。作者另外报告使用双臂 YAM 进行少量真实 π0.5 运行；没有公开足以据此计算总体真机成功率的完整分母。该文章为合作方自身报告，未由本站复验；它说明跨评测执行与记录已有方案，不能仅靠宣传确认所有部署功能或实际采购。
- [Simbiotic](https://www.simbiotic.dev/)网页面向机器人团队描述 Git 提交触发云仿真和指标记录，当前标价为每月 99 美元加每 GPU 小时 0.40 美元，并给出 20 回合示例。页面是供应商报价和能力声明；具体硬件限制、适用工作负载、上线与实际账单未经验证。它属于云仿真基础设施，不是按 benchmark 阅读文章的订阅价。
- [OLO Robotics 定价页](https://olo-robotics.com/pricing)列仿真、机器人开发和部署支持：个人 Premium 页面显示按年计费折算每席每月 69 英镑，含每月 10 小时云仿真；企业档和支持另行区分。税费、计费周期与限制以页面为准。它的导航/仿真/集成服务不是公开基准成绩数据库，价格只说明供应商如何挂牌，不说明有人成交。
- [Roborama 产品页](https://roborama.com/product/)构想以 API 使用策略、硬件与场景进行测试；但其[运行状态文档](https://roborama.com/docs/live-runtime/)明确当前列出的两个任务运行在仿真 cell，实物 cell 尚不进入队列；容器、checkpoint、endpoint 策略仅测试模式，实际运行暂不按美元计费。[价格页](https://roborama.com/pricing/)所列费率是目标服务与测试模式报价，不应当作已经交付的真机服务或实际成交价。页面展示 612 次、3,812 美元的代码片段是示例，不应充当已验收客户案例。本文未接触其私有 design-partner 环境。

## 产品判断与仍需验证的问题

这些例子表明“跑自己的策略、追踪失败、接入软硬件、降低评测耗时”已有商业和开源方案，但其交付能力、成本结构和成熟度差异极大，均比整理发布成绩重。网页报价及作者实验不能证明客户愿意为本站的资料整理付款。

可研究的轻量需求是让读者在评测前快速找到任务、版本、可运行资源、已知复现障碍和费用边界；读者是否使用、是否比原项目 README 或现有工具更省时，仍需目标用户对照。若缺少独立验证的用户需求及持续维护能力，不应由这些价格反推本站应收费多少。
