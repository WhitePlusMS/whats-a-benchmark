# 机器人视觉问答：数据、成绩与执行边界

核查日期：2026-11-09。本文是公开资料和工作树的只读对照；没有自行评测、操作机器人或访谈用户。不同来源的分数没有经过统一复测。

## 站内与外部候选

本次按名称检索 `content/benchmarks`，未发现 Robo2VLM、RoboVista、BOP-ASK 的同名条目；这不证明没有关联数据或别名。它们是本轮查到的外部候选，不是证明站内已有这三项。未标记评测的名称、摘要和任务描述复查见[已有盘点](2026-11-09-untagged-fulltext-and-sample-integrity.md)：包含物理、空间或动作相关词不等于直接控制机器人。

| 项目 | 输入和输出 | 解读边界 |
| --- | --- | --- |
| 站内 [V*Bench](../../content/benchmarks/vstar-bench.json) | 通用静态图像上的视觉问答 | 可涉及物体属性或空间关系，不是机器人控制测试。 |
| 站内 [GraspNet-1Billion](../../content/benchmarks/graspnet-1billion.json) | 真实图像数据上的候选抓取检测与 AP | 存在真实场景数据，不代表该 AP 是真机执行成功率。 |
| [Robo2VLM](https://berkeleyautomation.github.io/robo2vlm/) | 用人遥操作机器人轨迹生成图片和多选问题，测试视觉语言模型回答 | 作者称数据含 684,710 道问答、源自约 176k 条真实机器人轨迹；这些问题数不是 684,710 次机器人执行。论文实验使用抽取的测试问题，不能把数据集总量写成单个模型的测试题数。 |
| [RoboVista](https://github.com/ehehee/robovista) | 474 道机器人应用场景的图片多选题，覆盖工业、农业、家庭等 | 题目是问答；仓库另称问答表现与真机双臂实验有关联，但此处未复核实验细节，不能直接将问答分数称作真机成功率。作者已有数据浏览器、评测脚本及成绩表。 |
| [BOP-ASK](https://bop-ask.github.io/) | 从物体图像及三维信息构造视觉问答，涉及物体位姿、可抓取性和交互等 | 作者还在论文中报告独立的真实机械臂抓取放置实验；应分别记录问答与执行实验，不把它们合并为一个成功率。 |

2026-11-10 按 `RoboChrono` 名称检索本地 `content` 与研究目录未命中；只说明该名称的有限检索结果，不排除关联内容或别名。[RoboChrono 论文](https://arxiv.org/abs/2609.36605)用真实机器人及人手操作录像构建 39 个场景、1,816 段成功执行视频和 34,713 个评测实例，考察当前动作、下一动作、跨视角及时间顺序等七类视频理解；这些录像的真实来源不等于被测多模态模型操控机器人，也不等于 34,713 次真实运行。六类为选择题准确率，动作时间定位另用 tIoU 阈值指标，不能合成同一任务成功率。

[作者仓库](https://github.com/mfan-res/ROBOCHRONO)说明 39 个场景中 31 个的动作顺序没有分支，部分下一动作问题可能依赖顺序记忆；题目和答案公开、没有隐藏测试集。作者报告五个开源模型在受控子集上移除视觉输入后的表现变化，仅是这组实验，不能推广到所有模型或全部问题。作者[官网](https://continuity3.github.io/robochrono/)已有真实录像预览和论文结果可视化，是该题解释与展示的直接替代。[GIM 数据卡](https://huggingface.co/datasets/gimai/RC-GIM)与 [Tianji 数据卡](https://huggingface.co/datasets/gimai/RC-Tianji)各标 CC BY 4.0；官网展示的另一来源预览则标 CC BY-NC 4.0。具体素材应逐项核对来源与许可，本次未下载、复核题目或重新发布素材。

例如，[Robo2VLM 论文第 5 节](https://arxiv.org/html/2505.15517)说明从数据抽取训练和测试样本，并在测试样本中为各模型随机抽取题目；不同数字对应不同层级。[BOP-ASK 论文](https://arxiv.org/html/2511.16857)报告真实机械臂上的 15 项抓取放置任务，基线与微调模型分别完成 0 项和 10 项；这里的分母是该实验任务，不能当成整个问答集的结果，也不能推断其他模型的表现。

## 同一来源体系里也需要追溯口径

截至核查时，[RoboVista 固定版本的 GitHub README](https://github.com/ehehee/robovista/blob/b4fa27be29414ed2ec62178b6be86a541a288264/README.md)零样本成绩表写 GPT-4o 为 **49.6%**；[Hugging Face 数据卡](https://huggingface.co/datasets/sy-xie/robovista)的标准提示成绩表写 **48.5%**。后者明确说明 474 道中排除 14 道、按 460 道计分并使用改进的答案解析器。本次也读取了数据卡固定版本 `75aa5726cbf98d4ce578dc254d89dc0d2c6d40b8` 的原始 README，确认该分数及计分说明。

目前没有足够证据确认 GitHub 表的完整分母、模型版本或两处差异原因；不能认定某一成绩错误，也不能断言是删题或解析方式造成差异。比较与入库时至少保留来源、快照、模型配置、题目范围、提示、解析方法和未知项。数据卡的 `train` 分片名称只说明发布时的数据组织，不能因此推断这 474 题都用于训练。

## 开发者问题与竞争

[一位 ROS 课程作者的公开提问](https://www.reddit.com/r/ROS/comments/1xgmw5t/i_trained_smolvla_on_49_demos_of_a_ros_2/)描述了仿真温室的 49 条人类示范：40 条训练、9 条留作测试；最近示范复制基线的动作误差低于其训练的 SmolVLA。作者特别说明结果来自已记录数据，尚不能证明机器人能摘到番茄，并询问如何设计更困难的测试以及多少次真实运行才值得相信成功率。这是作者自述与单个问题，未独立验证其代码或实验，不代表普遍市场需求，也不证明他会使用本项目。

这个例子支持继续检验“读者能否区分离线指标、问答和真实执行”的需求，但现有产品并非空白：[PhAIL 项目作者](https://www.reddit.com/r/robotics/comments/1s8tt6j/project_i_benchmarked_4_robot_ai_models_on_a_real/)已公开描述真实料箱抓取、吞吐、视频及日志；RoboVista 自己也提供了题目浏览和榜单。是否有人会因为本站的中文解释、来源对照或任务边界而选择本站，仍需要读者对照测试，不能仅凭发现问题断定存在产品优势。
