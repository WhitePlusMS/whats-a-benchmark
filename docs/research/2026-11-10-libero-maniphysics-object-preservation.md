# LIBERO 关联研究：完成任务与物体是否完好

核查日期：2026-11-10。此处为论文作者报告，未独立运行代码、复测模型或实测机器人。

[本站 LIBERO 条目](../../content/benchmarks/libero.json)关注机器人操作和知识迁移。[ManiPhysicsBench 论文](https://arxiv.org/html/2610.02802)在 LIBERO 和 SimplerEnv 上构造不同材料与易损程度的操作任务，并在仿真结束后评估抓取是否可能损坏物体。本次按名称搜索 `content/benchmarks` 与现有 `docs/research` 未见 ManiPhysicsBench；这不代表对其他名字或全网的完整排查。论文新增的物体与任务不是原始 LIBERO 官方排行榜的同一测试集，不能把结果写回原榜或视为原榜准确率。

## 三个分数的分母不同

论文记录每次任务是否完成，以及评估的每次抓取是否可能损伤物体。使用其物理模型，所有被评估的抓取都未达到损伤条件，才算该次物体完好：

| 指标 | 定义 | 如何解读 |
| --- | --- | --- |
| SR | 完成任务次数 ÷ 全部次数 | 只衡量任务完成，不含完好条件。 |
| Safe SR | 完成任务且判定物体完好次数 ÷ 全部次数 | 同时满足两项条件。论文中的 safe 特指评估范围内的物体保持，不涵盖人员安全、碰撞、跌落等全部安全问题。 |
| PR | 完成任务且判定完好次数 ÷ 完成任务次数 | 条件为任务已完成；一次也没完成时未定义，不等于 0。 |

例如 [论文表 4](https://arxiv.org/html/2610.02802)中，LIBERO 场景下 π0 抓取 portion cup 的 SR / Safe SR / PR 为 **58.3% / 50.0% / 85.7%**。按 12 次等权试验与表中一位小数倒推，相应是 7/12、6/12、6/7；这是按论文给出百分比反推，不是本次对逐次轨迹的独立复核。[附录](https://arxiv.org/html/2610.02802)描述每个模型—物体直方图按 12 次轨迹等权平均。另一模型在同物体上 SR 为 0、PR 标记为 `–`；把它写成 PR 0% 会抹掉分母为零的区别。

## 汇总结果与控制条件

论文表 3 的 SimplerEnv 汇总行报告 **48.3% / 13.5% / 27.9%**；表 4 的 LIBERO 汇总行报告 **12.3% / 1.9% / 15.1%**。汇总覆盖论文选取的公开模型及三类物理轴的中、高难度物体，不包括低难度物体；不同环境、机械臂、模型集合及任务不能只看这两行就归因。百分比四舍五入后，13.5/48.3 约 27.95%，论文原表 PR 27.9%，不应要求显示数字直接相除严格相等。

作者在固定轨迹上对记录的接触力缩放、限制于执行器力上限，再重新计算判定：SimplerEnv 中默认设定 Safe SR 13.5%，半倍力重算 24.9%，两倍力重算 3.6%；在 LIBERO 分别是 1.9%、3.4%、0.9%。作者指出半倍情形低估部分饱和抓取的力，所以这个 Safe SR 是上界。这是**同一轨迹的事后敏感性分析**，不是三种增益各自重新跑出的机器人对照试验。

论文还将 QwenGR00T 公开检查点与重新训练版本比较，报告 SR 70.8% → 38.9%，Safe SR 13.9% → 25.0%。但作者明确新训练只使用 Bridge 数据及 LoRA，公开检查点使用 Bridge 与 RT-1 混合数据及不同配置，所以不能把变化单独归因于标签策略。此处保留比较目的及混杂因素，不称为干净消融。

## 不能直接推出真实损坏概率

评估先在刚体仿真中收集接触点和力，再依据物体几何、参考材料参数、假设的硅胶垫及有限元求解计算潜在损伤。作者表示结论仍需真实机器人验证，且未涵盖跌落、撞击、形变对后续动作的影响。不同物体的参数证据和损伤阈值并不等同：例如煮土豆 1% 受影响体积分数是作者设定的用途判据，并非本文实测所有土豆的失效门槛。
