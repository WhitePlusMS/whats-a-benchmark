# 吸盘抓取：候选分数、真机抓取与清箱

调查日期：2026-11-09。对照当前本地条目、公开代码、论文和用户讨论；未训练模型、运行评测、下载新数据或操作机器人。论文结果均为作者报告，并非本站实测。

## 一个具体模型在两种评测里的数字

本站 [SuctionNet-1Billion](../../content/benchmarks/suctionnet-1billion.json) 已包含真实采集场景、物体级密封候选标签和官方演示；其中 test_seen 图像没有叠加预测，000 物体标签也不是执行成绩。其[官方页面](https://graspnet.net/suction)说明共享 GraspNet 场景但评测吸盘抓取。

[MultiGraspNet 论文](https://arxiv.org/html/2602.06504)恰好同时给出 S1B（SuctionNet 基线）两类结果，可用于解释为什么不能把一个百分比都叫作机器人成功率：

| 论文中 S1B 的数字 | 数据与指标 | 如何理解 |
| --- | --- | --- |
| 28.31 | 论文表 I，RealSense、吸盘、seen，AP | 对预测候选计算的评测指标；采用论文整理对齐的数据和协议。 |
| 16/30（53%） | 论文表 V，单吸盘实机、seen，成功清除物体数/物体总数 | 在作者的实际桌面抓取设置中，30 个物体实例中清除了 16 个；不是上面的 AP。 |
| 39.11% | 同一实机表的抓取成功率指标 | 以抓取尝试为分母的指标，与清除物体比例的分母不同；取值为论文表格报告，未核对原始记录。 |

表 I 的 seen 和表 V 的 seen 属于不同试验与数据上下文，不能当作同一批场景的离线与实机配对；53% 是四舍五入后的 16/30。实机部分共五个 seen 场景、30 个物体实例，另有五个 unseen 场景、25 个物体实例；每次抓取后重新感知，连续三次未抓到任何物体则停止。小样本与重复摆放限制了外推，未将这些结果作为工厂现场生产水平。

官方 [SuctionNet API 评测实现](https://github.com/graspnet/suctionnetAPI/blob/master/suctionnetAPI/suctionnet_eval.py)在 `eval_scene` 中按候选置信度排序，并在 0.2、0.4、0.6、0.8 四个阈值及最多前 50 个候选上计算；这并不是每个候选都由机器人执行。代码文档中的张量形状注释与当前四阈值实现表述不同，本次没有运行或审计完整代码，不据此断言实际输出存在错误。

## 实际料箱中，失败后怎么处理也决定结果

[MetaGraspNetV2 论文](https://publikationen.bibliothek.kit.edu/1000168221/152209863)报告另一套真机料箱试验：使用固定吸盘与相机，逐场景复原物体摆放，物体提起并在移动到指定位置期间保持接触才算成功。每个物体在一个场景中失败两次后由人工移除。论文区分成功清除物体数/抓取总次数和成功清除物体数/物体总数；因此仅看抓取成功率，不能知道有多少物体最终依靠人工处理。

论文写四组测试各有 40 个场景、400 个物体实例，合计 2,040 次抓取尝试；400 不是总尝试数，2,040 也不是每组尝试数。样本涉及复用的物体和场景，不等于 1,600 种独立物体；不同论文硬件、物料和停止规则不同，不能把其百分比与 MultiGraspNet 直接拼成榜单。

## 真实问题与已有解决资料

- [SuctionNet issue #10](https://github.com/graspnet/suctionnet-baseline/issues/10) 中，提问者询问是否有像 GraspNet 一样的自有数据标注工具；[issue #8](https://github.com/graspnet/suctionnet-baseline/issues/8) 的另一位提问者称使用自己的数据并调整深度范围后，预测中心分数图不理想。当前页面未见项目方回复；不能从单个自报推断故障原因，也不证明没有解决工具。
- [MetaGraspNet 官方仓库](https://github.com/maximiliangilles/MetaGraspNet)已经提供真/合成数据说明、可视化和依据自有 mesh 采样吸盘候选的脚本；这针对其自己的模型和格式，未验证其可直接生成 SuctionNet 同格式标签或解决上述提问。数据、脚本和素材的实际许可需分开核对；仓库明确将数据标作非商业，不能因公开就假定商用许可。
- [MetaGraspNet issue #22](https://github.com/maximiliangilles/MetaGraspNet/issues/22)中，用户询问失效的合成数据下载地址；维护者解释部分场景渲染图与掩码存在几像素偏移，后于 2025-04-22 报告修订版已上传，提问者关闭 issue。仓库之后也说明合成版本修订。此为维护者报告，未独立验证修订包及所有样本，不能推断该问题影响 SuctionNet 或所引用论文的具体成绩。

## 对项目的含义

这是一个与现有具身条目、工业仓储都直接相关的阅读任务：从论文中的吸盘 AP、实机抓取成功率和清箱率出发，找到各自的对象、场景、分母、停止/人工介入规则和数据版本。网站可以尝试把这些来源串联，但原论文、代码和仓库已给出不少信息；是否比直接查原文更省时，需要目标读者比较，不能仅据 issue 数量推断市场规模或付费意愿。
