# 模型榜单的缺失成绩：预测、已报告结果与排序

调查日期：2026-11-10。聚焦用户原设想中的模型成绩与 GPQA；未运行模型、验证预测、审核全部上游数据或做读者测试。

## 一个此前未记录的直接竞品

[benchgap](https://benchgap.net/)提供按基准和模型查看的榜单、成绩矩阵、模型比较、拟合曲线、不同评测框架的差异页面和公开 API。它从外部来源汇总已有成绩，并依据模型在其他相关评测中的已知成绩估计缺失值；不是由其对每个模型重新执行全部基准。[方法页](https://benchgap.net/method)和界面明确区分 `measured` 与 `estimated`，并允许保留无法估计的空缺。其所谓 `measured` 是来自上游的已报告结果，并不自动代表 benchgap 独立测试，更不自动保证所有原始来源协议一致。

以用户特别关心的 [GPQA Diamond 页面](https://benchgap.net/b/gpqa-diamond/current)为例，页面声明数据截至 2026-11-07：GPT-6 Astra 一行是 **96.0% measured**，Claude Sonnet 5.5 一行是 **96.0% estimated ±1.0 个百分点，低置信度**。两行数值相同，但后者明确是模型推算，不是该站声称已经对其完成 GPQA 实测。页面按分数将已报告和估计行排列在一起，但分别标注来源类型；本次未验证筛选交互或原始各模型的具体运行。网站数字可能更新，此处只记录读取时显示的快照。

该站的方法声称只在同类能力评测间建立映射、训练所需共同模型数至少为 5、预测不会递归地作为下一项预测输入，并根据拟合误差等标置信心。它自己报告的遮盖已有数据测试覆盖约 70% 被遮盖格子、平均绝对误差约 4.7 个百分点；这不是所有预测的正确率，也不保证单个模型落在 `±` 所示范围。方法页说明这个误差提示对整体实现均方根误差有所低估；随站点更新结果可能变化。本次未运行其校验或确定未来新模型的误差。

[代码仓库](https://github.com/hollorol/benchgap)说明评分数据来自 BenchLM，代码为 MIT，而上游数据按该站所述为 CC BY-NC 4.0；开放 API 或代码不自动赋予商业再分发全部原始成绩的权利，使用前还应核对上游实际条款和来源。该竞品进一步削弱了“做一个完整模型成绩矩阵、保留来源和设置”是空白赛道的假设，但它的预测功能并不等同用户原计划的厂商发布成绩归档。

## 真实讨论及其利益关系

[项目发布讨论](https://www.reddit.com/r/LargeLanguageModels/comments/1xjb2l8/we_built_a_leaderboard_that_fills_in_missing/)由项目作者发布，不能计作独立用户。一个评论者建议按时间记录未来实际结果和先前预测的偏差，提出新模型可能超出已拟合范围；同一条评论同时宣传自己的营销服务，存在明显利益关系，不能计作经验证的用户需求。另一位评论者对把模型和测试聚在一起表示认可，仅是简短公开评论，并未表明持续使用或付费。

## 同名成绩排序未必能支持细微优势

[榜单统计研究](https://arxiv.org/html/2609.07785v1)分析了 SWE-bench Verified、AgentRewardBench 和 tau2-bench 等公开记录。对于作者选定的 SWE-bench Verified 原始前十条提交，两两组成 45 组；按作者设定的两百分点实际差距门槛和逐对置信区间，5 组稳定、1 组对目标分布敏感、39 组证据不足；采用其同时区间时，45 组均未排除零差。该分析基于特定数据快照、被观察到的前十、重加权方法和统计规则，不意味着排行榜分数无效，也不能推断所有榜单差距都不显著。

同文分析 tau2-bench 特定共同覆盖的主设置：四次尝试至少一次成功的 pass@4 相比 pass@1 提升 17.7–20.4 个百分点；这不是模型升级造成的变化，也不能当作所有模型通用差距。本站已有 [τ²-bench 条目](../../content/benchmarks/tau2-bench.json)，其版本字段提示须注明领域与 release；不因名称相近就把该研究涉及的结果归属于本站某条样例。

## 对本站的可执行含义

- 把厂商原报、第三方测得、用户自测和推算分别作为来源类型；没有来源或关键设置时显示未知。即使都叫 GPQA，也要核对版本、设置与执行者。
- 未经用户验证，不把“用预测填满矩阵”作为新增需求：它提升展示覆盖，但可能让推算被当成已测成绩，且需要明确许可和持续评估误差。
- 可做一个不开发的新阅读测试：给读者上面的两条 GPQA 行，询问是否都实测、能否据此说两模型同分；再给一个 pass@1 与 pass@4 的案例，询问是否可直接比较。与原站或论文对照，记录答对率、耗时和是否愿意再次使用；现阶段没有测试结果。
