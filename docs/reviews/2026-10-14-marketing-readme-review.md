# 项目定位、推广文稿与 README / SVG 审核记录

## 最终定位与表达

- 定位：面向中文读者的 AI 评测资料库，帮助大家看懂模型发布报告里的任务与分数。
- 主读者：阅读模型发布报告的中文 AI 使用者；次读者：开发者、产品人员、资料作者与学习者。目标读者来自现有功能的适用场景推导，尚未验证实际用户分布。
- 核心价值：用任务和可公开样例解释能力；连同评分条件、版本与局限阅读分数；保留官方来源供读者继续核对。
- 使用 product-marketing 保存 v1 上下文，按 oil-tone 调整通用推广文稿、短版介绍与双语 README；采用 beautify-github-readme 的纯 SVG 方式完善静态封面。
- 本轮只修改文案与视觉素材，没有修改网站功能、评测内容、依赖、运行或部署配置。

## 功能与事实依据

大量搜索与完整阅读由 GPT-6 LUNA 进行，仅提供事实描述；主代理核对定位、表达与验证结果。

作者源与生成目录均为 151 项已发布评测、10 类能力、149 条站内样例记录，分布于 138 个条目；发布资料 17 组。样例数量按条目中的样例记录数求和，不是全部原题数或外部题库规模。公开成稿不加入易过期的收录数字，不使用客户、口碑或流量等未经提供的证据。

HumanEval/0 的 `[1.0, 2.0, 3.0]`、阈值 `0.5`、结果 `False` 来自题目 doctest。封面标注为预期结果，不宣称运行模型或执行评测。站内展示范围取决于公开程度和许可，文案未承诺完整题库下载。
