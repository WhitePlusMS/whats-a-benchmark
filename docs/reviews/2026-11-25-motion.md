# 2026-11-25 全站状态动效复查

动效用于交代状态和位置。保留读者当前的焦点和阅读位置，直接操作优先交付结果。本轮仅在本地预览。

## 按状态变化检查

| 状态变化 | 共用处理 |
| --- | --- |
| 进入新页、返回、跳锚点 | 站内路径变化只轻过渡首要标题或导读。首次加载、历史位置恢复及直达锚点直接定位，搜索更新不会重播页面入场。 |
| 出现、消失 | 手机筛选从底边出现，居中弹窗轻移，主题菜单向触发按钮收回，悬停说明只淡变。对比栏和撤销提示短入快出，关闭后即停止交互。页内长折叠内容展开时轻淡入，收起时立即回到正文位置。 |
| 按下、悬停、选中 | 常用按钮按下微缩。目录和任务内容/原始数据采用同一种移动底色，键盘焦点环即时显示。颜色过渡仅用于正在交互的控件，换肤不触发批量颜色动画。 |
| 换内容、移除、排序 | 搜索、筛选、排序和图解步进即时换内容。换题时只提示新标题。已展现过的默认分组在清空搜索时复用，过滤期间旧分组隐藏。 |
| 图标、数字、进度 | 外观图标和对比勾在原位反馈。数字直接更新，IFEval 字数进度只缩放填充，进度变化不反复计算容器宽度。 |
| 加载、完成、出错 | 加载文字即时出现，等待较久时再显示旋转标记。完成反馈继续提供明确状态，能撤销的操作保留入口。报错保留原有说明和重试按钮，直接呈现。 |
| 拖动、画格、缩放与媒体 | 拖动、键盘调节、画格、媒体进度和图片缩放直接响应，避免额外插值和等待。 |

`src/styles/motion.css` 统一四档时长，按压 80ms、常用反馈和退场 120ms、局部状态 160ms、页面导读与筛选弹层进入 220ms。使用一条减速曲线。支持原生顶层过渡的浏览器保留弹窗退出画面。状态、焦点和关闭逻辑不等待动画。系统开启减少动态效果后保留选中态、文字和焦点，关闭过渡与平滑滚动。

## 验证与独立评审

- Gemini 按六类状态给出方案，建议长目录禁错峰、进度用 `scaleX()`、图解和画格即时响应，弹层、对比和撤销承担必要的过渡。采用现有组件与更短的全站时长。保留已有明确状态文案，避免在实时筛选时反复播报更新。
- GPT 独立复审识别了全站换肤引发的大量并行动画、ARC 经颜色过渡产生的延迟，以及按钮与弹层在同一事件循环内关后再开可能失配。修正后独立回验通过，普通与减少动态效果两档的格子均即时着色，弹层能快速重开并恢复焦点和滚动锁。
- 浏览器实际走查覆盖 320px、390px、1280px，浅色和深色。核对了搜索往返、目录导航、筛选焦点和退出、图片 150% 缩放与重开、对比清空撤销、案例模式、IFEval 进度和终端图解快切。减少动态效果通过浏览器媒体特性模拟验证。
- 82 项相关回归通过，另有 GPT 复审运行的 80 项相关测试。两批部分重合。
