## 审查结果

| 原则 | 原有障碍 | 本轮处理 |
| --- | --- | --- |
| 系统能判断，不留给用户 | 分类固定数量无法反映当前搜索；读者要试出空分类 | 数量随搜索和其他条件变化，禁止误选零结果分类，医疗专题复用现有筛选规则 |
| 此刻没用，就不出现 | 单案例仍有两枚无效换题按钮；空草稿也显示清空 | 隐藏这些控件；移除非必要分类总数及手机页眉重复 GitHub 入口 |
| 能替人做，就直接做 | 无结果恢复需重新输入搜索；分享需自行复制地址栏 | 放宽筛选时保留输入与视图，提供明确复制链接和失败时可选中的链接 |
| 同一件事，处处一样 | 桌面与手机状态需一致；指标名与摘要出现重复 | 共用筛选/撤销状态；38 项相同摘要只展示一次，指标名前缀不重复 |
| 按下有回应，再按能收回 | 分类不能再次取消，ARC 参考只能揭示 | 分类可取消，参考可收起且保留查看事实，复制/上限/清空有可见反馈 |
| 不打断手上的事 | 拼音选字触发 URL 更新；存储异常可能中断设置 | 等选字完成再搜索，清空后保留输入焦点，禁用存储时当前换肤仍生效 |
| 常用易做，丢东西难误碰 | 对比清空、IFEval 替换无恢复；ARC 重开丢撤销历史 | 对比和片段替换可撤销，移除重复重开，保留可撤销的画板操作 |
| 界面自己说明自己 | README 宣称未实现的批量查询；主题菜单键盘语义不完整 | 文案匹配实际功能；采用普通切换按钮，Tab/Esc/返回焦点与触控范围一致 |
