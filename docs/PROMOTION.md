# 到底测什么？一个帮助理解 AI 评测的中文资料库

阅读模型发布报告的时候，我们会看到 HumanEval、SWE-bench、GPQA 等评测名称，以及对应的分数。要理解这些结果，还需要知道模型实际完成了什么任务、分数如何计算，以及使用了什么版本和评测条件。

[「what's a benchmark? · 到底测什么？」](https://whiteplusms.github.io/whats-a-benchmark) 是一个中文 AI 评测资料库。它围绕每项评测整理任务说明、可公开样例、评分方法、版本关系和官方来源，方便大家从报告里的名称继续了解具体内容。网站无需登录即可阅读。

以 HumanEval 为例，它要求模型根据函数签名和说明补全 Python 函数，再通过单元测试检查结果。站内可以查看具体任务与参考答案，阅读 `pass@k` 的含义和采样条件，并沿着来源链接查阅原始资料。任务样例与评分说明放在一起，能够帮助我们理解这个分数对应的能力和条件。

目录可以按名称、能力或发布方搜索，也支持粘贴一组评测名称批量查询。需要了解几项评测的差异时，可以选择两到三项并排比较，核对它们的输入输出、评分方法、版本和限制，再分享对比链接。原始材料、节选和本站解读分别标注，样例是否能够在站内展示取决于公开程度与许可。

这个项目适合阅读模型报告的 AI 使用者、需要核对评测条件的开发者和产品人员，以及整理技术资料的作者与学习者。它用于阅读和查找资料，不运行模型评测，也不生成统一模型排行榜。模型成绩仍以对应的原始报告和榜单为准。

可以从一项正在阅读的评测开始，也可以按编程、工具使用、多模态或真实工作等能力分类浏览。如果发现说明需要纠正，欢迎在 [GitHub 仓库](https://github.com/WhitePlusMS/whats-a-benchmark) 提出问题，并附上对应的官方来源。

## 短版介绍

「到底测什么？」是一个中文 AI 评测资料库，帮助大家理解模型发布报告里的任务与分数。可以搜索评测名称、查看可公开样例与评分说明，比较两到三项评测的条件和版本，再继续查阅官方来源。无需登录，样例按公开程度与许可提供。
