# 将评测、版本关系和评测报告分别建模

本项目服务于需要理解模型发布资料的读者。条目身份由任务与评测规则确定，版本、子集和衍生关系附带来源；厂商只调整提示词、工具或预算时，其结果归入报告及运行配置，不新增一个虚构的独立评测。发布方属于描述信息，不能代替评测类型或公开程度。

如果按发布会图表中的每一个名称直接建独立条目，后续会产生重复收录和错误比较；如果只合并到原始题库，又会隐藏真实存在的子集与衍生评测。显式记录关系能保留两者差异，也使中文解读可以解释名称之间的联系。

依据：[SWE-bench Verified 官方说明](https://openai.com/index/introducing-swe-bench-verified/)与 [Anthropic 的 SWE-bench 运行说明](https://www.anthropic.com/engineering/swe-bench-sonnet)。条目展示规则详见 PRODUCT_DESIGN.md。
