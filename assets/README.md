| 素材     | 入口                                                         | 内容                                                |
| -------- | ------------------------------------------------------------ | --------------------------------------------------- |
| Logo     | [品牌说明](brand/README.md)                                  | 彩色与黑白 SVG、透明与白底 PNG、ICO                 |
| README   | [中文封面](readme/hero.svg) / [英文封面](readme/hero-en.svg) | 对应语言的 SVG、GIF，以及目录、手机、主题与案例截图 |
