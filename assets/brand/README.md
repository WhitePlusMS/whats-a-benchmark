# 到底测什么？Logo

「题卡与对号」是「what's a benchmark? · 到底测什么？」的项目标识。题卡对应评测任务，对号对应答案与评分；默认采用深蓝题卡、一条题干短线和橙色对号。

![题卡与对号的彩色、黑色及白色正式版本](preview.svg)

站内切换主题时，题卡与题干跟随主题色，对号保持橙色。浏览器标签和独立导出素材使用默认蓝橙配色。

## 文件与用途

| 文件                         | 用途                    |
| ---------------------------- | ----------------------- |
| `benchmark-symbol.svg`       | 彩色透明矢量原稿        |
| `benchmark-symbol-black.svg` | 黑色单色版              |
| `benchmark-symbol-white.svg` | 白色单色版              |
| `benchmark-symbol.png`       | 512×512 透明彩色 PNG    |
| `benchmark-icon.png`         | 512×512 白底图标        |
| `favicon.ico`                | 16 / 32 / 48px 白底图标 |
| `../../public/favicon.svg`   | 站内标识与浏览器标签    |
| `preview.svg`                | 彩色与黑白版本预览      |

<p><img src="benchmark-icon.png" width="128" alt="白色圆角底的深蓝题卡与橙色对号图标"></p>

站点实际使用 `public/favicon.svg`。`src/App.vue` 通过 `import.meta.env.BASE_URL` 生成地址，再以 SVG `<use>` 引用 `#brand-mark`，使图形继承页面的 `--theme-brand`；作为独立 favicon 读取时使用深蓝回退色。沿用现有生成和发布流程，无需复制几何路径、增加组件或增加换肤监听器。

## 配色与构造

| 角色               | 色值                                |
| ------------------ | ----------------------------------- |
| 题卡与题干（默认） | `#092D56`，站内跟随 `--theme-brand` |
| 对号               | `#F58A08`                           |
| 图标底色           | `#FFFFFF`                           |

统一使用 `viewBox="0 0 256 256"`。主体边界为 x=16–240、y=28–224；题卡边框厚度 18，对号主体沿 45° 方向，右上开口保留独立间隙。只有实色填充，透明区域由真实几何留白形成。全部 SVG 不依赖字体，页眉站名继续使用现有网页文字。

## 使用规则

- 保持正方形比例，勿拉伸、旋转或改变图形之间的位置。
- 彩色透明版放在浅色纯底上；深色底使用白色单色版或带白底图标。
- 页眉采用 36px，700px 以下采用 32px；固定宽高并防止 flex 挤压。
- 站内默认主题为「深海蓝」，原有紫、靛蓝、绿、橙、玫红、石墨六种主题继续可选。选中的颜色沿用既有机制保存及恢复。
- 白底图标上的题卡使用主题的深色原色，保证深色模式下图形与白底的对比；页面的链接与按钮继续使用既有暗色派生色。
- favicon、PNG、ICO 和独立宣传素材保持默认蓝橙配色，避免标签页随浏览界面选择改变品牌识别。
- 浏览器标签使用 SVG 或 ICO；较大展示使用矢量原稿或 512px PNG。
- 单独排版时，图形外至少留一个题卡边框厚度的空白；白底图标自带内部留白。
