测什么

根据真实 GitHub issue 在修复前仓库状态上生成补丁，再用测试验证。Verified 是人工质量筛选的 500 项子集；筛选关注问题描述是否明确、FAIL_TO_PASS 测试是否公平，以及其他重大质量问题。[1]

评分与比较条件

评分指标

resolved rate

越高越好 · 官方 leaderboard 口径

主结果为 solved/resolved rate：完整通过该任务的 FAIL_TO_PASS 与 PASS_TO_PASS 测试才计为 resolved。部分通过不计分。

适用限制

  • 仅覆盖 Python 仓库；其他语言生态不适用。
  • 部分题目依赖测试环境完整性，复现需 Docker harness。
  • 不同报告的执行预算与 retry 策略不同，横向比较前先核对协议。
