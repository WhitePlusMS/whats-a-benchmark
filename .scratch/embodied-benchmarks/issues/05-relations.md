# 评测与相关资源怎样关联

Label: wayfinder:grilling
Type: grilling
Status: resolved
Blocked by: 01, 03

## Question

评测、数据集、模拟器和比赛如何表示类型与关系，保证相关资源可被找到，同时不被误认为评测本体？原版、衍生版本和年度赛制如何区分？

Assignee: Codex

## Answer

用户确认：评测详情关联数据集、仿真平台、比赛等资源，分别标明类型并链接官方来源。原版、子集、衍生版和挑战赛版本当范围或协议不同时分条目并互相关联；不因出现新版本就合并或覆盖旧版本。单一资源可供多个评测引用，不把数据集或模拟器伪装成评测；是否独立资源页仅在确有需求时再做最小设计。
