# 具身评测如何分类与筛选

Label: wayfinder:grilling
Type: grilling
Status: resolved
Blocked by: 02

## Question

在选定的界面方向下，任务类型、仿真或真机、机器人形态、数据模态等应作为主分类、筛选还是详情属性？如何避免多标签造成重复收录或混淆？

Assignee: Codex

## Answer

用户选择按任务能力分类，同一评测可属于多个分类并从各分类找到，但仅维护一份评测条目。专区只按任务分类筛选；仿真/真机、机器人类型、输入与动作、成功条件等信息先在详情页展示，不在专区增设这些筛选项。所有字段以官方资料为准，未披露如实说明。分类名称和具体映射仍需根据完整候选清单与官方资料核实。
