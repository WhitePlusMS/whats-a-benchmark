# 具身详情页样例卡片采用什么布局

Label: wayfinder:prototype
Type: prototype
Status: resolved
Blocked by: none
Assignee: Codex

## Question

在现有详情页中，具身评测的数据样例以画面、过程还是数据为主组织，才能更直观地解释机器人任务？

## Answer

用户选择 **B：过程优先**。样例主要按任务执行顺序组织，展示对应的图片或视频和简明步骤说明；设计沿用已有样例查看器、主题和媒体组件。原型使用 RoboTwin 官方任务说明，自制图形仅为示意，不能充当原始数据或动作记录。正式素材须逐项核验数据版本、来源、许可；缺少可公开样例时如实展示说明与官方入口，不编造图片或轨迹。

证据：[方案 B 截图](../variant-b.png) · [三方案原型](../sample-card-prototype.html) · [RoboTwin 官方任务](https://robotwin-platform.github.io/doc/tasks/handover_block.html)。

范围：本决定仅覆盖详情页样例卡片；专区入口、首页分类和筛选继续单独讨论。
