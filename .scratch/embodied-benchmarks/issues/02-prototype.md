# 具身专区入口与分类界面如何呈现

Label: wayfinder:prototype
Type: prototype
Status: resolved
Blocked by: none

## Question

顶部导航进入的独立专区怎样组织首屏、任务分类、筛选与卡片，才能既保持项目现有风格，也让读者快速区分机器人操作、导航等任务？请用可切换的低成本原型与用户共同比较，再确定方向。

## 已有约束

优先复用现有导航、主题变量、筛选控件、卡片与响应式样式；原型比较布局和信息组织，不另建一套视觉系统。

## 用户关注

具身评测卡片和数据样例应直观展示真实任务；研究在既有组件基础上适配图片、视频、轨迹或其他合适的数据形式，并明确来源与许可。

样例卡片布局已由 [具身详情页样例卡片采用什么布局](07-sample-layout.md) 单独记录；本票仍讨论专区首页入口、分类、筛选和目录卡片。
