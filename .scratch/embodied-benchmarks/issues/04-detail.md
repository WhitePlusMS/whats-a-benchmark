# 具身评测详情与样例如何表达

Label: wayfinder:grilling
Type: grilling
Status: resolved
Blocked by: 01, 02

## Question

机器人任务说明、观察输入、动作、成功条件、轨迹或视频、版本和协议如何与现有详情页与样例组件衔接？哪些需要新增呈现，哪些应复用？未公开数据或不可转载案例如何如实说明？

## 已有约束

优先复用现有详情页、样例查看器及媒体展示；只有已验证的具身展示需求无法满足时，才提出必要的最小扩展。

Assignee: Codex

## Answer

用户授权根据真实数据决定表达，不为了固定格式舍弃更好的内容。复用现有详情与媒体查看器；样例按任务过程为优先阅读方式，但仅当有真实可核验的步骤、轨迹或对应媒体时使用；连续视频、单张图片、点云/结构化数据、真实任务指令等允许选择更适合的呈现或补充必要扩展。不得把推断步骤、示意图或人类演示称作真实模型运行结果；公开范围、素材许可、数据版本、来源必须明确，缺失部分如实说明。可按内容说明环境、机器人、观测、动作、目标、成功判定、数据与评测协议，已知才显示，不为凑字段制造内容。
